# Data-Analysis-Projects-from-Great-Learning-Texas-McCombs-School-of-Business
These two project were data analysis projects from Great Learning.  Great Learning partnered with Texas McCombs School of Business and Microsoft to teach data analysis using Excel, SQL, Python, and Microsoft's PowerBI. <br><br>
The New Wheels project focused primarily on using SQL to sort, filter, clean the data, and create aggregations to analyze the data and create a report for stakeholders that can be used to make actionable decisions. <br><br>
The Movie Lens project focused on using PowerBI on the front end and python in the backend to create a dashboard of metrics using 3 different data sets, a list of movies, a list of users, and a list of ratings.  Through these sources of information the dashboard was created to show different insights as to which gender preferred which type of genre, number of movies released by genre, average rating of the movies, a breakdown of user location, users by age and occupation, a graph of ratings based on age of the user, and another graph showing average rating based on the movie release sorted by decade.
